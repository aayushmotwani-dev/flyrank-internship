# FL-07 — Empty but Live

This is the first hosted shell for my backend portfolio. It is intentionally small: the point of this milestone is a reachable URL, not a finished design.

## Chosen stack

- Static HTML and CSS.
- Public GitHub repository.
- GitHub Pages as the free host.

## What is live

The page says my name and states the one-line proof claim. It has no case-study layout yet; the content map, identity kit, and cases remain in the linked Week 3 repository and Claude Project so the next build step starts from real material.

## Checks

- Open the GitHub Pages URL in a private window.
- Open the same URL on a phone or narrow viewport.
- Confirm the page is reachable without a GitHub login.
- Confirm the visible claim matches the proof statement and does not add unsupported scale claims.

The public repository is the source for this milestone. The live URL is added to the FlyRank submission after GitHub Pages is enabled and visibly reachable.
